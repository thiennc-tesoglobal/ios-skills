# Consumable Purchase Routing

## Problem/Feature Description

A SwiftUI app with an existing `StoreManager` needs a custom button for a 100-coin consumable. The backend supports app-account reconciliation. The task does not include subscriptions, offers, or a new paywall architecture.

## Output Specification

Create `consumable-purchase-plan.md` with the purchase result handling, verification, idempotent fulfillment, finish ordering, recovery, and focused tests. Preserve the existing store boundary.
