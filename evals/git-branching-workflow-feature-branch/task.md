# Feature Branch Creation and Upstream Sync

## Problem/Feature Description

Prepare a new feature branch for an iOS Apple Pay checkout flow. The branch must conform to team naming conventions, branch off the latest remote `main`, and maintain clear separation from other ongoing tasks.

## Output Specification

Specify the complete git command sequence to fetch remote references, branch cleanly without affecting local uncommitted changes, and verify the branch naming taxonomy. Explain the rationale for rebasing versus merge bubbles when preparing for code review.
