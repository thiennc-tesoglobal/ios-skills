# Local Calendar Reminder Routing

## Problem/Feature Description

An iOS app needs a daily 8:30 AM medication reminder that users can edit or disable. It is entirely on-device: there is no provider server, rich media, communication notification, or Live Activity.

## Output Specification

Create `local-reminder-plan.md` with a concise implementation and verification plan. Keep the solution scoped to local scheduling, authorization, request ownership, calendar behavior, and edit/disable handling.
